# Legal NER & Segmentation

Research software for named entity recognition and structural segmentation of Portuguese judicial decisions.

## Data protection

This is a **public code repository**. Do not commit raw decisions, individual annotations, model checkpoints, MLflow runs, or derived datasets containing judicial text. Store these outside Git and use locally generated data for tests.

## Development

Changes are developed in feature branches and reviewed through pull requests. The initial implementation will provide an auditable import and validation pipeline for Phase 1 annotations and share a canonical schema with Phase 2.
